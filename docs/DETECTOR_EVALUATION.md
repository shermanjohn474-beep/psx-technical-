# Detector evaluation (synthetic benchmark)

Generated by `backend/scripts/evaluate_detectors.py` with 15 seeds per cell.

* **Recall**: share of noisy re-generations of the canonical formation detected as CONFIRMED.
* **FP rate**: share of flat-noise / steady-trend series (no formation) with a CONFIRMED detection.
* **Random walks** can contain genuine formations by chance, so that column is an upper bound on false positives, not a pure FP rate.

Limitations: synthetic formations are idealised; real-market performance must be measured on a separately labelled set of real PSX charts. Noise 0.5 roughly doubles bar-to-bar noise relative to the formation amplitude and shows degradation.
